# Quick Start — LibreMobileDev for Grok Build

> From zero to a mobile review cue in under 5 minutes.

## Prerequisites

- Grok Build installed and working
- A mobile app repo (Flutter / RN / native) you own

## Install skills (repo-local)

```bash
git clone https://github.com/HermeticOrmus/LibreMobileDev-Grok-Build.git
cd your-project
mkdir -p .grok/skills
cp -R /path/to/LibreMobileDev-Grok-Build/skills/* .grok/skills/
```

Or user-global:

```bash
mkdir -p ~/.grok/skills
cp -R /path/to/LibreMobileDev-Grok-Build/skills/* ~/.grok/skills/
```

## First-run teach cue

1. **Offline** — "Run offline-first on sync and conflict policy."
2. **Perf** — "Run mobile-perf for startup and jank budget."
3. **Store** — "Run app-store-checklist before submit."
